# Чужий текст у місті (CITY-73, рішення 74)

Імена й тікери монет, назви запусків, вивіски кварталів, назви островів і команд, імена мешканців — це текст сторонніх
людей. Помічник і моделі його читають. Модуль чистить такий текст до того, що бачить людина, і пояснює кожну зміну.

Правила ті самі, що для будь-якого тексту, який читає модель: невидиме — геть, обернений напрям — геть, слово-двійник — замаскований текст, а неміряне — «не виміряно», не нуль.

## Що робить

| Знахідка | Ім'я, вивіска, острів, команда | Тікер | Текст для моделі |
| --- | --- | --- | --- |
| Невидимі символи: нульової ширини, з'єднувачі, селектори варіантів | видаляються (`invisible`) | видаляються | видаляються |
| Блок тегів Unicode — «ASCII-контрабанда» | затримується | затримується | затримується |
| Двонапрямні перемикачі: RLO, LRI, RLM та інші | видаляються (`bidi`) | затримується | видаляються |
| Керівні символи, розмітка, токени шаблону чату | прибираються (`control`, `markup`) | прибираються | прибираються |
| Латинське слово з гомогліфом іншого письма | затримується (`mixed-script`) | затримується | затримується |
| Слова-накази моделі; прохання ключа чи сід-фрази (англ., укр., рос.) | затримується (`instruction`) | затримується | замінюються на `[withheld…]` |
| Тікер, що видає себе за відому монету (`S0L`, `UЅDC`, `USDC` на чужому мінті) | — | `lookalikeOf` → не «verified» | — |

Затримане ім'я на екран не виходить. Вежа тоді стоїть без імені або зовсім не стоїть, вивіска лишається порожньою.

Чесні цифри дає `measured.ts`. Якщо джерело цифру не надіслало, екран пише «Not measured» / «Не виміряно», а не нуль.
Виміряний нуль лишається нулем.

## Виклики

```ts
import { cleanSymbol, cleanName, cleanSign, cleanIslandName, cleanCrewName, shownText } from "lib/world/text-safety/clean.ts";
import { lookalikeOf } from "lib/world/text-safety/lookalike.ts";
import { measured, shownFigure, NOT_MEASURED } from "lib/world/text-safety/measured.ts";
import { forModel, modelField } from "lib/world/text-safety/for-model.ts";
```

Кожен виклик повертає `{ ok: true, text, reasons }` або `{ ok: false, reason, reasons }`.

## Де вже вбудовано

- **Вежі міста** — `city/lib/market/normalize.ts`. Чистяться тікер і ім'я. Двійник відомої монети не отримує
  «verified». Невиміряні цифри записуються в `Tower.unread`, а `towerFigure` показує їх як «Not measured».
- **Запуски в місті** — `city/lib/launch/feed.ts` і `towers.ts`. Чистяться ім'я й тікер творця, вежа із затриманим
  тікером не будується. Цифри, яких двигун не прочитав, — `unread`.
- **Пошук і картка монети** — `city/lib/search/sources.ts`, `city/lib/coin/read.server.ts`.
- **Будівля монети в кварталі** — `city/lib/quarter/objects.ts`.
- **Картка розвідника** — `city/lib/agent/rule.ts` (`explain`): невиміряне показано як «Not measured».
- **Помічник** — `lib/assistant/data/dexscreener.ts` (`label`, через неї йдуть усі зовнішні мітки), `lib/agent/context.ts`
  (тікер у посиланні), `lib/agent/suggestions.ts`.
- **Ім'я мешканця світу** — `lib/world/api.ts` (`claim`): ім'я з гомогліфом чи наказом відхиляється.

## Вбудовано після злиття (звірка 29.10)

- `city/components/hud/Hud.tsx` — картки веж: ціна, капіталізація, ліквідність, трейдери й «Organic» через
  `towerFigure` («Not measured» замість нуля).
- `city/lib/launch/hall.ts` («Зал») — тікер і ім'я монети на білборді через `shownText`; затриманий тікер на білборд
  не виходить.
- `city/lib/feed/**` (стрічка) — бере вежі й запуски, уже почищені в `normalize.ts` і `launch/feed.ts`.

## Лишилось

- `lib/ring/**` (Ринг). Сценарій агента — власний наказ гравця своєму агентові, тож слова-накази там — гра;
  `scenarioText` уже прибирає двонапрямні й нульової ширини символи. Блок тегів Unicode — рішення лінії Рингу.
- Назва команди (`Crew.name`): у `lib/world` запису назви команди ще немає; коли з'явиться — `cleanCrewName`.

## Готові виклики для задач, яких ще немає

- **Острови (CITY-54).** Назву острова при записі пропускати через `cleanIslandName`. Затримана назва — відмова
  `BAD_REQUEST` з тим самим коротким рядком, що й для імені мешканця.
- **Вивіски кварталу (CITY-55).** Текст вивіски — через `cleanSign`, потім у чергу модерації.
- **Помічник у місті (CITY-10).** Усе, що місто передає моделі (назви веж, описи, вивіски), — блоком
  `forModel({...}, { name: 'name', symbol: 'symbol' })`. У блоці лише ключі `untrusted_*`.
- **Шлюз моделей (CITY-45, `lib/models`).** Шлюз приймає готові повідомлення й тексту не чистить. Чистить той, хто
  кличе, через `modelField` чи `forModel`.

## Сейф

`lib/vault/screen.ts` уже ловить у спробі гравця приховані символи, гомогліфи й шифри. Слова-накази в спробі — це сама
гра, тож їх не прибирають. Охоронець іншого чужого тексту не читає. Нічого не вбудовано.
