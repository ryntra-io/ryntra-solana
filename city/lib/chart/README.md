# Графік вежі (CITY-5a)

Тап по вежі → «Chart» у картці вежі → живий графік ядра на місці картки: на столі — вікно, що тягнеться за голову й
розтягується за кут; на телефоні (і на малому столі) — повноекранний лист. Закрити — хрестик або Escape; картка вежі
вертається.

## Що на графіку

| Що | Звідки | Файл |
| --- | --- | --- |
| Свічки й обсяг, інтервали 1m … 1D | двигун: `/api/spot/candles` (GeckoTerminal, найглибший пул) — той самий читач, що в графіка ядра на споті (CH-17) | `candles.ts`, `feed.ts` |
| Остання свічка закривається ціною вежі | ціна вежі з читання міста (`/api/city`), поки воно живе | `ChartWindow.tsx` |
| Шар «Market» — великі угоди, творець, вихід з кривої, падіння ліквідності | двигун: `/api/spot/token?part=overview` | `marks.ts` |
| Шар «Entry» — «Your entry» | «Мої вежі» CITY-7: `basisOf` над записом угод гаманця (`/api/growth/cards`), лише читання | `entry.ts` |
| Факти ризику — ліквідність, холдери, вік | вежа з читання міста; позначки — лише межі двигуна (пул < $10 000) і міста (ринку < доби) | `facts.ts` |
| Ціна в голові | жива ціна міста; поки читання міста — збережений знімок, найновіше закриття двигуна | `candles.ts` (`headPrice`) |
| Логотип монети | двигун: `/api/icon/<mint>`; зайнятий шлюз — ще одна спроба; без логотипа — перша літера монети | `icon.ts`, `CoinIcon.tsx` |
| Buy | наявна картка угоди: `useTrade.getState().openFor(tower, 'buy')` за вимикачем `TRADE_OPEN` з `city/lib/trade/gates.ts` (`NEXT_PUBLIC_RYNTRA_CITY_TRADE`, той самий, що в Buy картки вежі); картку не змінено | `ChartWindow.tsx` |

## Вигляд — місто, ядро лише малює свічки (рішення 75)

- Графік ядра (`RyntraChart`) — лише рушій малювання свічок і обсягу. Його панель, легенду, знак і рядок стану сховано
  (`chart.module.css`); індикаторів немає (`indicators=[]`).
- Усе навколо — міське: рядок інтервалів (чипи міста), підпис бару під вказівником (час, закриття, рух — лише поки рука
  на графіку; канал перехрестя — `readout.ts`), «i» — джерело, пул і вік даних одним рядком (`detailsOf`).
- Порожні стани — чисте темне скло без картинки (жодного згенерованого міста, що не наше): один
  рядок; поки йдуть свічки — тиха помаранчева смуга світла.
- Вікно стає на своє місце з першого кадру (`startBox`): заглушка, вікно й збережене місце — одне; без стрибка.

Місто нічого не рахує в числах: адаптер графіка ядра — `SpotChartFeed` з
`app/solana/workspace/spot/core-chart-source.ts` (лінія «Графіки»), без змін. Коли CITY-13 прибиратиме старі екрани,
цей файл переїжджає разом із адаптером (у `lib/`), а не йде з ними.

## Шари — API для інших районів (CITY-5d і далі)

Шар — це позначки в моменти часу й рівні поперек графіка однієї вежі. Кожен шар — чип під графіком, людина вмикає й
вимикає його. Район додає свій шар одним викликом, не торкаючись файлів графіка:

```ts
import { setChartLayer, clearChartLayer } from '@/city/lib/chart/layers';

// Позиція перпа на SOL: вхід, ліквідація, TP/SL — рівні; заповнення — позначки.
setChartLayer({
  id: 'perps',
  label: 'Perps',
  mint: 'So11111111111111111111111111111111111111112',
  levels: [
    { id: 'entry', price: 187.4, label: 'Long entry' },
    { id: 'liq', price: 151.2, label: 'Liquidation', kind: 'alert' },
    { id: 'tp', price: 205, label: 'Take profit' },
  ],
  marks: [{ id: 'fill-1', t: Date.parse('2026-10-28T10:15:00Z'), side: 'buy', label: 'Long 2×', own: true }],
});

clearChartLayer('perps'); // коли позиції немає
```

- `id` — унікальний; новий виклик з тим самим `id` заміняє шар. `market` і `entry` — власні шари графіка.
- `mint` — вежа, на графіку якої шар малюється.
- Ціни — звичайні числа в доларах; графік сам ставить кожен рівень на свій крок ціни. Час — мс від епохи.
- `kind` рівня: `level` (лінія, яку людина тримає) або `alert` (ціна, на яку чекає). Позначка: `trade`, `event` або
  `alert`; `own: true` — угода самої людини.
- Шар без жодної позначки й рівня не показує чипа. Вимкнений чип лишається вимкненим і на інших вежах.
- Нічого не надсилається: рівень ніколи не стає ордером. Перетягування ліній з наміром угоди (`trading` у графіка ядра)
  — окреме розширення, коли воно знадобиться Біржі.

## Перевірки

- `node --test "city/lib/chart/*.test.mjs"` — дані → свічки, ціна входу, інтервали, порожні й помилкові відповіді,
  шари, факти, місце вікна.
- `node city/lib/chart/shots.mjs [out] [baseUrl]` — знімки стіл і телефон на фікстурах (заглушка гаманця, без мережі) і
  заміри: кадри й зайнятість головного потоку з графіком закритим, відкритим і з хрестиком, що бігає по свічках
  (`chart-fps.json`). FPS сцени з GPU міряють на стенді: у хмарі WebGL малює програмно.
