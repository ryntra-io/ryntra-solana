# `/methodology` — where the figures come from

Since 2026-09-26 (the new site) `/methodology` is a page again:
every figure a person sees in Ryntra, the source the product reads it from, and
when. `page.tsx` renders it; `methodology-copy.ts` holds its words in English
and Ukrainian, each row checked against the code that reads the figure.

From 2026-08-19 until then the address was a permanent redirect into the
handbook, and this directory held only data: `content.ts` — the old
methodology summary in twelve locales — and `copy.ts`, its supporting copy.
They describe the product of that time, no route renders them, and they stay
only because the SEO and public-identity tests still read them; deleting them
is a change to those tests, not to this page.
